# Mini PDA - Café Ordering System ☕

A simple Python-based PDA ordering system created for a café.

## Features

- Table selection
- Menu categories
- Product selection
- Quantity selection
- Automatic price calculation
- Multiple items per order
- Receipt generation
- Random order number

## Technologies

- Python 3

## About the Project

This project was created as part of my Python learning journey.
It helped me practice variables, user input, conditionals, loops,
lists, functions, calculations, and formatted output.
